# Battle Line Planner for Android

Build army lists, manage your collection and keep game information close at hand.

**[Download the latest Android test app](https://github.com/whackBadger/battleline-planner-downloads/releases/latest/download/Battleline-Planner.apk)**

[Version details and release notes](https://github.com/whackBadger/battleline-planner-downloads/releases/latest)

## Install on your phone

1. Open the download link on your Android phone and download **Battleline-Planner.apk**.
2. Open the downloaded file. If Android asks, allow your browser or file manager to install this app, then confirm installation.
3. Open **Battleline Planner**.

Requires a 64-bit Android device running Android 8.0 or newer. This is an alpha test build; features are still being developed.

Already have Battleline Planner? Install the newer APK over it. **Do not uninstall first**—your lists, collection and photos are stored on your device.

## Get future updates

Open **Dashboard → Settings → Check for Updates**. If a new version is available, choose **Download update**, then **Install update**. Android may ask you to allow installations from Battleline Planner once, and asks you to confirm each installation.

The download link above stays the same as new versions are published. If your existing version has no update button, install the latest APK from this page once to add it.

## Update reference data

**Settings → Update from BSData** refreshes the supported 11th-edition catalog independently of app updates. Saved army points remain as recorded; some rules and reference cards still require app updates.

## Your data

This download starts with an empty collection and army library. It contains no personal army lists, inventory or photos. Your own saved data stays on your device. Use **Settings → Export backup** to keep a copy or move to another phone.

This repository contains downloads and release information only.
